## 1. 概要

**项目类型**：Unity idle《伐木老友》。

**玩家口径**：总用户约一千；平均单局约 **1 小时** → 前 **1–2 小时**必须更密的撞墙 / 爽循环，墙长与爽长随时间变长，但压缩进约 **120′**。

**相对 v2**：公会目标从约 **150′** 过长 → v3 密阶梯压到约 **120′** 边界，公会约 **95′**。

### 1.1 范围（要 / 不要）

**要（本定版改动范围）**

- Buy：`baseGoldCost` 解锁价（主破局 + 少量夹层非主破局）
- AttackSpeed：**出售价** `goldCostMultiplier`（各 `*_AttackSpeed_d1`）；**效果值不动**

**冻结（勿改）**

- 开局金 **750**
- 「勿改清单」内项
- 收集工 / collectors
- MageGuild
- aspd **效果值** / `maxLevel` / `baseGoldCost`

### 1.2 主破局达标表（v3）

每波 **唯一主破局**（UI/文案只推这一个）。成功带约目标的 **±10–15%**。硬约束：火炮 **≤56′**，公会 **≤102′**。

| 主破局 | 目标′ | 成功带 | v3 建议价 | 原价 |
| --- | ---: | --- | ---: | ---: |
| 电击法师 | 9 | 7–11 | 225 | 275 |
| 弩炮 | 18 | 15–21 | 600 | 400 |
| 火焰法师 | 28 | 24–32 | 850 | 450 |
| 德鲁伊 | 40 | 36–44 | 800 | 900 |

v3 模拟均落在目标点附近（电击 9.0′ … 神殿 120.0′）；火炮 **52.0′**、公会 **95.0′**、神殿 **120.0′** 均达标。v2 公会 ~150′ 节奏对 1h 平均局过长，本版废弃该目标。

非主破局：斧 / 收集 / 弓 / 冰 **价不动**；锯、风、投石机夹在爽段，价略抬，避免抢主破局注意力（明细见参数表）。

## 2. 模型假设

1. **`sink_frac=0.96`**：约 **96%** 收入沉入单位升级，约 **4%** 攒向 Buy（沿用 v2，未改）。
2. 开局金 750，付早期开局消耗后约剩 **≈65**。
3. **优先解锁** = 当前波只攒主破局 Buy、不把金分到旁路 Buy；**不是**硬性「100% 存金不升级」。
4. 产金率增长律（自 v2 `rate_rebalance` 反推）：`R0≈693`，`dR/dt = 6.506 + 0.24·t`（金/分）；Buy 时跃迁 = IdleFramework `base_production×60`。
5. AttackSpeed **出售**倍率 **3.9–5.7 → 1.6–2.2**（效果值不变）。
6. **德鲁伊建议价 800 < 火焰 850**：时间序仍是火 → 锯 → 德鲁伊；**UI 必须只推当前主破局**，避免玩家按标价排序抢点德鲁伊。
7. 用二分反推各 Buy 建议价，使优先解锁到达落在成功带内。真实 ROI / 分心玩家会更慢，成功带已留 ±10–15%。

## 4. 战斗手感（经济表外）

经济表（Buy / aspd 出售）之外的战斗层问题，**不要**用改经济去「补」：

**现象（CultivationSpiritUnit）**

- 前期 miss：小 hitbox **0.62×0.66** + 慢斧 **2–2.5s** + predict clamp **1.3**
- 中后期树 HP 偏薄：`480 × 1.35^level`，但 `Tree_Level` **max=5** → 约 **2152** 封顶，而 v3 DPS 已抬高

**只改战斗、不动 Buy / aspd 经济**

- hitbox ≈ **0.90×0.95**
- 成长指数 ≈ **1.55**（保持 base **480**）
- `Tree_Level` max **5 → 12**

## 5. 可迁移方法

1. **把阶梯密度对齐平均局时长**：平均约 1h → 前 1–2h 必须密；勿按「全内容通关」把主高潮推到远超平均局之处（如 v2 公会 ~150′）。
2. **每波唯一主破局**：UI/文案只推一个；夹层价可略抬，避免抢注意力。
3. **经济导入与战斗成长分开**：Unlock / aspd 出售走导入表；hitbox / Tree HP / maxLevel 走战斗层，勿用经济补战斗、也勿用战斗改经济。
4. **Timing 验收用同一 sink 模型**：优先解锁 + `sink_frac`，不是「开局金能否秒买首破局」，也不是必须完整 2h AI 挂机。
5. **AI / 批量导入要对准真实路径与例外**：如 `Archer_CritChance-AttackSpeed` 无 `_d1`；冻结项（开局金、勿改清单、收集、MageGuild、aspd 效果/`maxLevel`/`baseGoldCost`）显式列出。
6. **经验包是参考不是唯一标准**：供后续验收、开发测试对照；数字以同目录材料为准。
