# 《铸剑大师》数值平衡经验包

> **本文为参考经验，不是唯一标准；用于后续验收、开发测试时对照。**
>
> 内容取自《铸剑大师》各版交付说明、回归报告、各组定稿表和 v3 整套数值表。文中数字都能在这些材料里找到；找不到的不写。第 3 节是待验证的思路，不是结论。
> 本文只是文档，框架代码里没有任何铸剑专属规则。

## 1. 概要

**项目类型**：单局经营 + 遗物构筑。

- 固定 25 位村民依次到来。玩家打剑、交剑、卖剑攒金币。
- **持有**金币达到 10 亿即通关（花掉的不算）。
- 开局 3 星可信度。没交到剑扣 1 星，归 0 失败。星只掉不回。
- 25 位接待完仍没到 10 亿，算未通关。
- 四个流派套装（入神、坚城、大成、伤痕），凑齐任意一套 4 件就能冲通关。遗物槽 8 格，也可以凑两套。

**最终验收目标与结果**（v3 回归，种子 1 / 20261022，各 4000 局）：

| 验收项 | 目标 | 结果 | 判定 |
| --- | --- | --- | --- |
| 四单套通关率 | 两种子都在 12%–18% | 入神 15.1% / 14.8%，坚城 16.9% / 17.7%，大成 13.2% / 12.7%，伤痕 16.0% / 17.6% | 过 |
| 刷新花费占卖剑收入（单套） | 15%–25% | 入神 17.4% / 17.4%，坚城 21.4% / 20.3%，大成 16.5% / 16.9%，伤痕 16.8% / 16.8% | 过 |
| 伤痕开剑 P(+99) | ≥18% | 18.6% / 18.8% | 过 |
| 六组双套倍率（÷ 同种子四单套最强） | 点估计 1.0–2.0× | 1.07×–1.86×，最高 入神+伤痕 1.86× / 1.68× | 过 |
| 整局免费刷新 | 恰好 1 次 | 两种子四单套 32000 局全部为 1 | 过 |
| 出货池 / 开局池 | 84 件 / 46 件 | 84 / 46 | 过 |

挂账：大成+坚城 在种子 20261022 的倍率 CI 下沿 0.97（点估计 1.07×），记 P2，不算失败。见第 4 节。

## 2. 通用方法（可迁移到其他放置 / 构筑项目）

### 2.1 模拟完整一局，玩家策略写成显式参数

- 用蒙特卡洛跑完整一局，不只跑单个子系统。
- 玩家怎么玩要写成参数，不要藏在代码里。铸剑里至少有这几个：
  - 开局三选一怎么挑（随机 / 挑最优）；
  - 凑齐主套后补位的买法（价值优先 / 锻造优先）；
  - 商人处什么时候买、买多少（例：单价 ≤ 持有金 × 0.5 才买；买铁累计超过收入 22% 不再买）。
- **验收要在多种玩家策略下都过。** 实际教训：
  - 开局改成"挑最优"后（v2z2b），双套 入神+伤痕 从约 1.9× 涨到 2.35×，入神+大成 2.42×，直接超线。
  - 锻造优先买法下，坚城 / 伤痕单套局分别有 11% / 7.5% 意外凑满入神 4 件，这些局通关率 41% / 77%（v2x）。
- 模拟里的 AI 买法要标明"仅模拟"，和游戏规则分开写。

### 2.2 验收看区间，不看点

- 多种子 × 每组 4000 局。铸剑每版至少 2 个种子。
- 通关率用 Wilson 95% 置信区间。4000 局时，15% 左右的通关率区间宽约 ±1.1 个百分点。
- 倍率（双套 ÷ 单套）用 delta 法求 CI，分子分母的误差都要算进去：
  `CI 半宽 ≈ 1.96 × r × sqrt((1−p)/(n·p) + (1−d)/(N·d))`，r 为倍率，p、d 为分子、分母通关率。
- 看下沿。点估计过线、下沿压线的，单独记账（P2），不要当作通过就忘掉。
- 配对实验（同种子、只开关一个效果）能把噪声压很低；池子变了 RNG 流就变了，不能配对，单格差的标准误约 0.8 个百分点。

### 2.3 组合构筑：分母、支配、上限

- 双套倍率的分母 = **同种子四单套里最强的那个**，不是"这一对里较高的单套"。目标 1.0–2.0×。
  - 两种口径差别可以很大：入神+大成 按最强单套是 1.85× / 1.77×，按本对较高单套是 2.07× / 2.13×。
  - **分母口径必须写进表里。** 早期几版分母用的是伤痕单套，和后来的口径不同，数字不能直接比。
- 支配检查：任何双套的绝对通关率要高于它两个成分单套（例：大成+坚城 20.5% / 19.0%，高于大成单套 13.2% / 12.7%）。
- 叠套强度要有上限：
  - 倍率 M 封顶 10（单套满池 7.5，双满 13.5 → 封顶 10）；
  - 第二套的件更贵（已满一套后，另一套的件每件 +2 铁）；
  - 双套闸门：同时满两套时，关掉部分转伤效果。
- 共享件要专门处理。玻璃沙漏原来同属入神和大成，玩家 7 件就能双满，倍率到 3× 左右；改成只计入神套后才正常（v2y→v2z）。

### 2.4 花费占比做经济体检

- 每个花钱出口单独算"花费 ÷ 卖剑收入"，取每局均值，再看买过的局的中位数。
- 铸剑的目标带是 15%–25%。超过上沿，说明这个出口太贵或太刚需；低于下沿，说明没人用或可有可无。
- 实例：
  - 伤痕的商人花费（买铁＋发条＋特殊剑）25.3% / 26.0%，略超上沿，记为参考项待观察。
  - 坚城买铁占比 9.5% / 9.7%，偏低。原因是坚城很少碎剑，铁用不完，属于构筑特点，不是数值问题。
  - 双套刷新占比只有 3%–8%：凑得早、刷得少，属正常。
- 占比要按流派分开看，不能只看全体均值。

### 2.5 漏洞 / 无限循环专项

- 转换环路（A 换 B、B 换回 A）一圈收益乘积必须 <1。
- 每个实体设次数上限。铸剑的做法：
  - 转伤（崩坏改成损伤）每把剑 1 次；
  - 倍率 M ≤ 10；
  - 继承剑每局 3 次；双生印每局 3 次、只复制 +30 以下；
  - 村民耐心 120 秒，限制单把剑的锤数。
- 看分布长尾，不只看均值。
- 案例：旧版"无限锤" bug 的来源是龙之心，整个龙相关内容已删，不再加回。

### 2.6 动态定价（刷新热度）

铸剑 v2z4 的遗物店刷新：

- 付费价 = 向上取整(300 × (1.6 + 0.02 × 村民序号)^heat)，村民序号从 0 起。
- 每刷新一次 heat +1，免费、付费、兑换券都算。
- 每来一个新村民 heat −0.25，最低 0（连过 4 个村民才降 1 格）。
- 整局只有第 1 次刷新免费；每位村民最多刷 8 次。
- 例：第 1 个村民处 heat 1–6 价格为 480 / 769 / 1,229 / 1,967 / 3,146 / 5,034 金；第 20 个村民处为 594 / 1,177 / 2,329 / 4,611 / 9,130 / 18,077 金。
- 目标：刷新花费占卖剑收入 15%–25%。结果单套 16.5%–21.4%，平均每局刷新约 17 次。

思路：价格同时随"短时间内刷了几次"和"游戏进度"上涨，又会随时间慢慢回落。连刷很贵，隔几位村民再刷就便宜。

### 2.7 遗物取舍规则

- 用配对实验测单件自身效果：同种子，强制把这件作为第一个补位件，效果开 vs 关。
- 单件对每个单套的自身效果 ≤ 约 3 个百分点 → 保留（必要时削档）；否则 → 不出现。
  - 例：追加供货许可原档 6.28 / 6.45 个百分点，削档后 1.88 / 2.30 → 保留；随身火炉 7.85 → 不出现。
  - 封印之心上限压到 1 仍有 3–4 个百分点、王的空杯压到 +2 仍有 5–9 个百分点 → 都判不出现。
- "不出现"只退出商店和开局池，套装成员资格保留。
- 缩池会抬高单套：出货池 90 → 84 件让单套约 +2 个百分点，后来靠调坚城、伤痕的崩坏抗性拉回。所以删件后要重新定标。

### 2.8 工程纪律

- **配置层层覆盖会悄悄钉死参数。** 实际踩坑：
  - 上层预设配置为了复现旧报告，把免费刷新钉在旧值 10 次。只改模拟默认值不会生效，新版本必须显式覆盖成 1，并逐局计数确认。
  - 同样的问题出过多次：旧预设把伤痕、坚城的崩坏抗性和附加铁钉在旧值，改了默认值也传不到用这个预设跑的结果里。
- 对策：
  - 每版锁定模拟文件，记录校验和；
  - 关键参数在回归脚本里加断言（跑之前断言参数等于定稿值）；
  - 单一负责人合并主线，其他人在副本里改，定参后再合并；
  - 旧报告要能逐位复现，复现用的预设和新预设分开。
- 分母口径、种子、局数、数据来源，都写进表里。

### 2.9 交付

- 给用户或 AI 看的表只留中文名和数字，程序名、参数名、代码位置放到单独的程序附表。
- 每张数值页写清楚"谁在用""改了会影响什么"。
- 设计口径和模拟代码不一致的地方，单独列一节（铸剑 v3 列了 10 条）。
- 已知小问题记 P2 挂账，写清楚本版为什么不改、下轮先看哪里。

## 3. 以前不擅长的机制：思路（待验证方向，不是结论）

以下是给后续项目准备的分析方向，都还没在实际项目里验证过。

| 机制 | 建议怎么看 |
| --- | --- |
| 里程碑翻倍 | 离散跳点处收益突变。按跳点分段算回本时间；看玩家在跳点前卡关多久（卡关时长分布）。 |
| 解锁门 | 看到达时间的分布，而不只是均值；每道门给出通过率及其区间。 |
| 合成 / 转换器 | 每个环路一圈收益乘积 <1；每种资源的各个出口占比分开看。 |
| 嵌套维度（第 n 层生产第 n−1 层） | 常数产出下第 n 层约为 t^n / n!。在对数空间里解析反推参数，避免浮点溢出。 |
| 献祭（局内转生） | 本质是时机最优化：选重置时机让"对数收益 / 秒"最大。扫重置阈值 x，画出曲线找峰值。 |
| 多选一天赋 | 每个选项都和最强选项比；做支配检查（有没有永远不该选的）；组合要设强度上限。 |
| 队列 / 建造等待 | 用离散事件模拟；把玩家在线时长、上线间隔建模成参数，按多种玩家类型分别验收。 |

## 5. 验收清单（下个项目可直接照做）

**模拟与口径**
- [ ] 模拟跑完整一局，玩家策略（开局挑法、补位买法、商人买法）都是显式参数。
- [ ] 至少 2 个种子 × 每组 4000 局。
- [ ] 每张结果表写明：种子、局数、参数版本、分母口径。
- [ ] 回归脚本对关键参数加断言；锁定模拟文件并记录校验和。
- [ ] 旧报告能逐位复现；复现用的预设不会被新版本误用。

**单套 / 流派**
- [ ] 每个流派通关率在目标带内，两种子都过，看 Wilson CI。
- [ ] 每个流派的关键能力指标（铸剑为开剑 P(+99)）过线。
- [ ] 换一种玩家策略再跑一遍，仍然过。

**组合构筑**
- [ ] 每个组合 ÷ 同种子最强单套，在目标倍率带内；delta 法 CI，记下下沿。
- [ ] 组合绝对通关率高于其成分单套。
- [ ] 共享件、叠套上限（如 M 封顶）检查过。

**经济**
- [ ] 每个花钱出口单独算占收入比例（均值 + 买过局中位数），按流派分开。
- [ ] 超出目标带的出口有解释或记账。

**漏洞**
- [ ] 转换环路一圈收益 <1。
- [ ] 每个"每剑 / 每局"次数上限都有，并在模拟里计数确认。
- [ ] 看过分布长尾（最大值、高分位），没有无限增长。

**遗物 / 选项**
- [ ] 每件新选项做配对实验，自身效果 ≤ 约 3 个百分点，否则削档或不出现。
- [ ] 删件、缩池后重新定标。

**交付**
- [ ] 给人看的表只留中文名和数字，程序附表单独放。
- [ ] 设计口径与模拟代码的差异单独列出。
- [ ] P2 挂账写清楚：数字、为什么不改、下轮先看哪里。
