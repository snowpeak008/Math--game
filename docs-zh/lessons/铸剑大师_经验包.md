## 1. 概要

**项目类型**：单局经营 + 遗物构筑。

- 固定 25 天（每天 1 位村民）。玩家打剑、交剑、卖剑攒金币。
- **持有**金币达到 **10 亿**即通关（花掉的不算）。
- 开局 3 星可信度。没交到剑扣 1 星，归 0 失败。星只掉不回。
- 25 天结束仍没到 10 亿，算未通关。
- 遗物槽 8 格；**每件遗物只有自己的单件效果，彼此没有组合加成**（与早期「四套装 4 件冲关」口径不同，见 4.3 历史路径）。
- 开局免费三选一（只从铁价 1 铁的遗物里抽 3 件）；四种开局心愿单：入神型 / 大成型 / 伤痕型 / 守价型。

## 2. 通用方法（可迁移到其他放置 / 构筑项目）

### 2.1 模拟完整一局，玩家策略写成显式参数

- 用蒙特卡洛跑完整一局，不只跑单个子系统。
- 玩家怎么玩要写成参数，不要藏在代码里。铸剑里至少有这几个：
  - 开局三选一怎么挑（随机 / 挑最优 / 按开局心愿单）；
  - 遗物店买法（按流派心愿单 / 随机乱凑）；
  - 商人处什么时候买铁、特殊剑（例：期望卖价高于售价且金币够才买；付费刷新不超过持有金一半）。
- **验收要在多种玩家策略下都过。** 实际教训：
  - 早期「四套装」路径：开局改成「挑最优」后双套倍率从约 1.9× 涨到 2.35×+，直接超线。
  - V8：会玩混搭 39.5% vs 乱凑 3.1%（差 36.5 个百分点）——通关率高度依赖买法，报告必须写清玩家口径。
- 模拟里的 AI 买法要标明「仅模拟」，和游戏规则分开写。

### 2.2 验收看区间，不看点

- 多种子 × 足够局数。V8 主线四种开局各 1 万局；独立复核另用种子 10000–19999。
- 通关率可用 Wilson 95% 置信区间。早期 4000 局、15% 左右时区间宽约 ±1.1 个百分点。
- 倍率（组合 ÷ 对照）用 delta 法求 CI，分子分母的误差都要算进去。
- 看下沿。点估计过线、下沿压线的，单独记账（P2），不要当作通过就忘掉。
- 配对实验（同种子、只开关一个效果）能把噪声压很低；池子变了 RNG 流就变了，不能配对。

### 2.3 组合构筑：分母、支配、上限

- 早期四套装路径：双套倍率的分母 = **同种子四单套里最强的那个**，目标 1.0–2.0×；**分母口径必须写进表里**。
- 支配检查：任何组合的绝对通关率要高于其成分。
- 叠套 / 叠效果要有上限（例：倍率 M 封顶；每剑 / 每局次数上限）。
- 共享件要专门处理（早期玻璃沙漏同属两套导致 7 件双满，倍率到约 3×）。

### 2.4 花费占比做经济体检

- 每个花钱出口单独算「花费 ÷ 卖剑收入」，取每局均值，再看买过的局的中位数。
- 铸剑刷新目标带曾用 15%–25%。V8 实测刷新 **13.3%**，略低下沿，已挂账。
- 占比要按开局 / 流派分开看，不能只看全体均值。

### 2.5 漏洞 / 无限循环专项

- 转换环路（A 换 B、B 换回 A）一圈收益乘积必须 <1。
- 每个实体设次数上限（转伤每把 1 次、继承剑每局次数、村民耐心限制单把锤数等）。
- 看分布长尾，不只看均值。
- 案例：旧版「无限锤」bug 的来源是龙之心，整个龙相关内容已删，不再加回。

### 2.6 动态定价（刷新热度）

思路：价格同时随「短时间内刷了几次」和「游戏进度」上涨，又会随时间慢慢回落。连刷很贵，隔几天再刷就便宜。

V8 定版（见 xlsx「商店与商人」）：

- 付费价 = 向上取整(**450** × (1.6 + 0.02 × 天数序号)^刷新热度)，天数序号从 0 起。
- 每刷新一次热度 +1（免费、付费、兑换券都算）。
- 每过 1 天热度 −0.25，最低 0。
- 整局第 1 次刷新免费；每天最多刷 8 次。

（早期 v2z4 底价曾用 300；勿与 V8 混用。）

### 2.7 遗物取舍规则

- 用配对实验测单件自身效果：同种子，强制把这件作为第一个补位件，效果开 vs 关。
- 单件对通关率自身效果过大 → 削档或不出现。
- 「不出现」只退出商店和开局池。
- 缩池会抬高构筑强度，删件后要重新定标。

### 2.8 工程纪律

- **配置层层覆盖会悄悄钉死参数。** 实际踩坑：上层预设为了复现旧报告，把免费刷新钉在旧值；只改模拟默认值不会生效。
- 对策：每版锁定模拟文件并记校验和；关键参数在回归脚本里加断言；旧报告复现用的预设和新预设分开。
- 分母口径、种子、局数、数据来源，都写进表里。

### 2.9 交付

- 给用户或 AI 看的表只留中文名和数字，程序名、参数名放到单独附表。
- 每张数值页写清楚「谁在用」「改了会影响什么」。
- 设计口径和模拟代码不一致的地方，单独列一节。
- 已知小问题记挂账，写清楚本版为什么不改、下轮先看哪里。

### 2.10 V7–V9 冲突：单把通关线 vs 多把占比不能同时硬卡

**可迁移教训**（V8 取舍写进定版）：

- 若中档等级（如 +80–94）的卖价**已经能单独越过 10 亿**，则「一把剑即通关」占比会 naturally 变高；同时要求「多把凑关 ≤30%」与「整体通关 ~40%」容易互相打架。
- V7→V8 主改摘要（xlsx「目标与实测」相对 V7）：+80 ×1.8→**×2.4**；铁价日涨 a 从 0.9 拉回 **1.2**（a<1 会越卖越便宜）；B0 200→**120** 补偿防碎 4 铁；+95 ×1.1→**×0.9**（否则 +99≈10.8 亿、一把通关冲到约 96%、+95 以上>60%）。
- V8 **优先保住**等级档分布（+80–94 为主、+95+ ≤30%）和整体约 40%，把「多把 ≈37%」「刷新 13.3%」「B0=120」「+95×0.9」记入挂账，测完再动；不在未测前为压多把去拆已过线的档位。
- V9 曾继续拧旋钮，**已搁置**——先玩法测试 V8，再决定要不要动挂账项。

## 3. 以前不擅长的机制：思路（待验证方向，不是结论）

以下是给后续项目准备的分析方向，都还没在实际项目里验证过。

| 机制 | 建议怎么看 |
| --- | --- |
| 里程碑翻倍 | 离散跳点处收益突变。按跳点分段算回本时间；看玩家在跳点前卡关多久（卡关时长分布）。 |
| 解锁门 | 看到达时间的分布，而不只是均值；每道门给出通过率及其区间。 |
| 合成 / 转换器 | 每个环路一圈收益乘积 <1；每种资源的各个出口占比分开看。 |
| 嵌套维度（第 n 层生产第 n−1 层） | 常数产出下第 n 层约为 t^n / n!。在对数空间里解析反推参数，避免浮点溢出。 |
| 献祭（局内转生） | 本质是时机最优化：选重置时机让「对数收益 / 秒」最大。扫重置阈值 x，画出曲线找峰值。 |
| 多选一天赋 | 每个选项都和最强选项比；做支配检查（有没有永远不该选的）；组合要设强度上限。 |
| 队列 / 建造等待 | 用离散事件模拟；把玩家在线时长、上线间隔建模成参数，按多种玩家类型分别验收。 |

## 5. 验收清单（下个项目可直接照做）

**模拟与口径**
- [ ] 模拟跑完整一局，玩家策略（开局挑法、买法、商人买法）都是显式参数。
- [ ] 多种子 × 足够局数；独立复核与主线对照。
- [ ] 每张结果表写明：种子、局数、参数版本、对照口径。
- [ ] 回归脚本对关键参数加断言；锁定模拟文件并记录校验和。
- [ ] 旧报告能逐位复现；复现用的预设不会被新版本误用。

**开局 / 构筑**
- [ ] 每种开局通关率在目标带内，看区间而不只看点。
- [ ] 换一种玩家策略再跑一遍（会玩 vs 乱凑），仍然可解释。
- [ ] 对照开关（如不卖特殊剑）比值过线。

**等级档与经济**
- [ ] 通关剑等级档分布在目标带（中档为主、超高档有上限）。
- [ ] 单把 / 多把通关占比有产品口径；冲突时明确优先项并挂账。
- [ ] 每个花钱出口单独算占收入比例，超出目标带的有解释或记账。

**漏洞**
- [ ] 转换环路一圈收益 <1。

**遗物 / 选项**
- [ ] 每件新选项做配对或对照，自身效果过大则削档或不出现。

**交付**
