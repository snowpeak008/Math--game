## 1. 概要

**项目类型**：Clicker Heroes 式放置点击 + 英雄雇佣 + 飞升 / 超越（压缩 100 区，目标约 3–4 小时通关）。

**玩家口径（模拟）**：「全程在场、偶尔点击」——刷怪约 0.3 次/秒，Boss 战约 4 次/秒；同一 Boss 卡住约 3 分钟后再过约 45 秒反应时间才决定飞升 / 超越。

**目标带**：通关 100 区落在 **195–225 分钟**。

### 1.1 范围（要 / 不要）

**要（已进模型 / 定版）**

- 英雄不限数量（压缩版 21 位）
- 英雄升级链
- 金身（镀金）
- 远古（古神，英魂购买；飞升后整池重分配）
- 先知 / 外域者（古魂购买；超越时远古与英魂清零）
- **后补**：宝箱怪（仅刷怪期望折入）
- **再后补**：全部 9 主动技能状态机 + 全部技能向远古进可购买池

**不要（本压缩定版未建模）**

- 成就
- 遗物 / 装备
- 雇佣兵任务
- 公会
- 红宝石店
- 时光跳跃
- 自动点击器
- 广告
- 离线收益

### 1.3 宝箱与技能拟合对照

**宝箱**

| 情形 | 通关′ | 说明 |
| --- | --- | --- |
| 仅加宝箱、未重拟合 | **173.8** | 偏快，首飞被推到 35 区（出带） |
| 重拟合终版（v3宝箱） | **197.7** | 用更高 boss_mult / gate_g、更低 hero_cost_k 等拉回 195–225′ |

固定参数：`chest_p = 0.05`，`chest_mult = 8.0` → 刷怪期望倍数 `1 + 0.05×(8−1) = 1.35`。只乘刷怪路径；**Boss / 关卡 Boss 击杀金币不乘宝箱**。

**技能**

| 情形 | 通关′ | 说明 |
| --- | --- | --- |
| 基线（chest 参 + 技能未拟合） | **203.2** | 9 飞升 / 2 超越；首飞 11.2′ / 25 |
| 重拟合终版（v3技能） | **202.3** | 8 飞升 / 2 超越；首飞 11.3′ / 25；首超 47.3′ / 50 |

技能验收要点（v3技能终版）：

- **9 技能均释放 ≥ 1 次**（实测次数示例：Clickstorm 13、Powersurge 12、Lucky Strikes 9、Metal Detector 7、Golden Clicks 6、Dark Ritual 11、Super Clicks 7、Energize 7、Reload 5）
- 技能向远古常买到：**Vaagur / Chawedo / Pluto**（各至少 1 级）
- **外域者无技能向扩展**；未扩先知集合（仍为 Xyliqil / Chor'gorloth / Phandoryss / Ponyboy / Orphalas）

## 2. 系统简述（压缩版）

- **结构**：4 章 × 25 区；每 5 区普通 Boss（约 30 s）；25 / 50 / 75 / 100 关卡 Boss（约 45 s）。
- **英雄**：不设上限；约每 5.7 区一位；升级链统一（L10 / L25 / L50 / L75 / L100 等）。
- **金身**：约每 12 区 1 个（飞升保留）；远古 Argaiv 放大金身收益。
- **英魂 / 飞升**：约 10 区起掉英魂；约 25 区解锁飞升；飞升后远古与英魂清零，**整池按估值贪心重分配**。
- **古魂 / 超越**：约 35 区解锁超越；超越时远古与英魂清零，先知保留等级。
- **宝箱怪**（v3宝箱起）：见 1.3。
- **主动技能**（v3技能起）：对齐状态机（每技能独立 CD / 持续时间；Energize 放大下一技能；Reload 缩短上一技能 CD；Dark Ritual 叠乘）；雇到前 9 位英雄即可解锁全部 9 技能。

### 3.3 远古 / 先知（要点）

- **核心远古**（英魂）：Siyalatas、Libertas、Mammon、Fragsworth、Argaiv、Morgulis、Solomon、Chronos —— 飞升后整池重分配，等级可回落。
- **技能向远古**（v3技能加入可购买池）：Vaagur（减 CD）、各技能时长向（如 Chawedo 等）、Pluto（Golden Clicks 金）等；终版常买到 Vaagur / Chawedo / Pluto，其余可为 0（可接受）。
- **先知**（古魂）：Xyliqil、Chor'gorloth、Phandoryss、Ponyboy、Orphalas；**无技能向外域者**。

## 4. 通用方法（可迁移）

1. **先定范围再定数字**：明确「要 / 不要」系统，避免成就 / 红宝石等未建模内容混进验收。
2. **玩家口径写死**：点击频率、卡住阈值、飞升 / 超越阈值都要可复现；报告里写清「全程在场偶尔点」这类假设。
3. **增量加系统 → 先看未拟合 → 再 ES 拉回目标带**：宝箱未拟合 173.8′ → 拟合 197.7′；技能未拟合 203.2′ → 拟合 202.3′。
4. **验收看区间**：通关目标带 195–225′，不是单点；同时看首飞 / 首超区与飞升、超越次数。
5. **飞升重分配是特征不是 bug**：远古等级在飞升间可回落；对比表必须按「飞升后状态」读。
